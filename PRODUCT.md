# Product

## Register

product

## Users

Linux players, including people unfamiliar with Wine or Proton, who want to install and launch Madium without manually managing runtimes, prefixes, dependencies, or terminal commands.

## Product Purpose

MadLinux turns the known Madium-on-Linux compatibility procedure into a guided installer. Success means a user can choose the Madium installer, let MadLinux prepare an isolated environment automatically, and launch Madium from one familiar desktop application.

## Brand Personality

Calm, dependable, approachable. It should feel like a conventional operating-system installer: explicit about the current task, quiet when things work, and helpful when something fails.

## Anti-references

No hacker-terminal aesthetic, neon gaming launcher, generic analytics dashboard, decorative glass panels, or unexplained Wine terminology. Technical output stays inside Diagnostics.

## Design Principles

- One obvious next action at every stage.
- Explain outcomes in everyday language before exposing implementation details.
- Make progress and failure recoverable and visible.
- Keep compatibility changes isolated and verifiable.
- Never imply that the app bypasses Roblox security or anti-cheat systems.

## Accessibility & Inclusion

Target WCAG 2.2 AA, keyboard navigation, visible focus, readable contrast, reduced-motion support, and status communication that does not rely on color alone.
